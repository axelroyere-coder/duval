# Duval Couverture 27 - Site Web Professionnel

Site web moderne et responsive pour Duval Couverture, expert en couverture et zinguerie dans l'Eure (27).

## 🎨 Caractéristiques

- ✅ Design moderne et professionnel
- ✅ 100% Responsive (mobile, tablette, desktop)
- ✅ Animations fluides et élégantes
- ✅ Formulaire de contact avec validation
- ✅ Navigation smooth scroll
- ✅ Optimisé pour les performances
- ✅ Code propre et bien structuré
- ✅ Sans bugs et testé

## 📋 Sections

1. **Hero Section** - Présentation accrocheuse avec call-to-action
2. **Services** - 6 services détaillés (Couverture, Zinguerie, Rénovation, Fenêtres de toit, Dépannage, Professionnel)
3. **Réalisations** - Galerie de projets récents
4. **À Propos** - Histoire de l'entreprise, statistiques et certifications
5. **Contact** - Formulaire de contact avec validation + informations de contact
6. **Footer** - Liens utiles et mentions légales

## 🛠️ Technologies

- **HTML5** - Structure sémantique
- **CSS3** - Styles modernes avec variables CSS, Grid et Flexbox
- **JavaScript (Vanilla)** - Interactions sans dépendances
- **Google Fonts** - Montserrat & Open Sans

## 🎨 Palette de Couleurs

- **Primaire**: Bleu (#1e3a8a, #1e40af)
- **Secondaire**: Orange/Doré (#f59e0b)
- **Accent**: Rouge (#ef4444)
- **Sombre**: Gris foncé (#1f2937, #374151)

## 📱 Responsive

Le site est entièrement responsive avec 3 breakpoints principaux:
- **Mobile**: < 576px
- **Tablette**: 576px - 968px
- **Desktop**: > 968px

## ⚡ Fonctionnalités JavaScript

- Menu mobile avec animation
- Navigation active selon la section
- Smooth scroll sur tous les liens
- Bouton "retour en haut" dynamique
- Validation de formulaire en temps réel
- Animations au scroll (Intersection Observer)
- Formatage automatique du numéro de téléphone
- Debounce sur les événements de scroll

## 🚀 Installation

1. Cloner le repository
```bash
git clone <repository-url>
cd duval
```

2. Ouvrir `index.html` dans un navigateur

Aucune installation ou build n'est nécessaire ! Le site fonctionne directement.

## 🔧 Personnalisation

### Modifier les couleurs

Dans `styles.css`, modifier les variables CSS dans `:root`:

```css
:root {
    --primary-color: #1e3a8a;
    --secondary-color: #f59e0b;
    /* ... */
}
```

### Modifier le contenu

Le contenu est directement dans `index.html`. Sections facilement identifiables avec des commentaires.
